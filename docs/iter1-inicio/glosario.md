# Glosario - Khanauky

| Término oficial | Significa | Evitar usar como sinónimo |
|---|---|---|
| Vendedor | Personal que registra la operación de venta. | Cliente, usuario. |
| Pedido | Solicitud que puede revisarse antes de la venta. | Venta. |
| Venta | Operación comercial confirmada. | Pedido. |
| Producto | Artículo disponible para comercialización. | Ítem, cuando genere ambigüedad. |
| Stock | Cantidad disponible de un producto. | Cantidad del pedido. |
| Pago | Registro o confirmación económica asociada a una venta. | Venta. |
| Almacén | Área donde se controlan las existencias. | Stock. |

## Regla de consistencia

**Pedido y Venta no son el mismo concepto.**

El pedido puede revisarse y modificarse antes de registrar la venta. La venta representa la operación ya confirmada.

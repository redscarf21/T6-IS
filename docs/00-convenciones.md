# Convenciones del proyecto Khanauky

## 1. Identificadores

Los identificadores deben ser únicos y mantenerse durante todo el proyecto.

- `REQ-###`: Requisito.
- `CU-###`: Caso de uso.
- `RSK-###`: Riesgo.
- `HU-###`: Historia de usuario.
- `ITER-#`: Iteración.
- `CLS-Nombre`: Clase del sistema.

## 2. Carpetas

- `docs/iterN-fase/`: documentos de cada iteración.
- `modelos/iterN/`: diagramas, archivos fuente y exportaciones.

## 3. Nombres de archivo

Usar minúsculas y guiones.

Ejemplos:

- `vision.md`
- `matriz-fase-artefacto.md`
- `checklist-coherencia.md`
- `actividad-registrar-venta.drawio`
- `actividad-registrar-venta.png`

## 4. Commits

Formato recomendado:

`ITERN: acción realizada (IDs afectados)`

Ejemplos:

- `ITER1: agrega Documento de Vision de Khanauky`
- `ITER1: agrega roadmap RUP`
- `ITER1: modela CU-003 Registrar venta con excepciones`
- `ITER1: agrega riesgos del modulo de ventas y almacen`
- `ITER1: corrige coherencia entre venta pedido y stock`

## 5. Versiones

Formato:

`vX.Y-iterN`

Primera versión prevista:

`v1.0-iter1`

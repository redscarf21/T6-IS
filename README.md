## Alcance de esta entrega
Esta iteración se concentra en el núcleo funcional de **registro de ventas y control de stock del almacén**.

La propuesta considera como funciones principales:

- Gestionar stock.
- Consultar y modificar un pedido antes de registrar la venta.
- Registrar venta.
- Registrar o confirmar pago.
- Mantener consistencia entre la venta registrada y el stock disponible.
